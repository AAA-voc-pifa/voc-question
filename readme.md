# 词汇题

## 杂乱的规划
#### AI 生成句子
让 AI 生成包含若干单词的**有哲理或科普或其他任何有意义的句子**。
就目前的 AI 发展水平来说，单词越多，生成结果质量越差（拼凑感太强）。
生成的句子应另交 AI 审核。

#### 用户解答
应提供“我不会”这样的选项

## 题型

#### 填空
+ 针对一个单词，生成句子
+ 挖去目标单词，让用户填，不提供选项
+ 如果用户需要提示，可以：
	+ 显示句子的翻译
	+ 多选一

#### 英译中
+ 针对一个单词，生成句子
+ 让用户翻译
+ AI 判题

#### 中译英
+ 针对一个单词，生成句子
+ 让 AI 翻译成中文
+ 给用户中文翻译和目标单词，让用户翻译成英文
+ AI 判题
